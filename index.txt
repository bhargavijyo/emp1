2.Looping statements -- used to execute a block of code until a condition met.
    1.for loop -- known number of conditions 
        syntax:
            for(initialization;condition;inc/dec){
                stmt;
            }
    2.while loop -- Executes the code as long as the condition is true.
        syntax:
            while(condition){
                stmt;
            }
    3.do...while -- Executes the code atleast once, then checks the condition 
        syntax:
            do{
                stmt;
            }
            while(condition);
    4. for...of -- used to iterate over the value of iterable objects like arrays and strings.

    5.for...in --Used to iterate over the properties of an object.
